# 🧬 BioCore Academy: Operación Unidades 1 y 2

Simulador de aprendizaje interactivo para preparar el **parcial de Biología Celular y Molecular**. Contiene **23 niveles temáticos** que cubren la totalidad de las Unidades 1 y 2, con tres modalidades de evaluación (selección múltiple, verdadero/falso y completar concepto), sistema de vidas, rachas, medallas de colección y **guardado automático local del progreso**.

## 💾 Sobre el guardado del progreso

**El progreso se guarda de forma LOCAL en tu navegador.** No se envía a ningún servidor, no requiere cuenta ni conexión a internet para funcionar.

### ¿Qué se guarda?

- ✅ Puntaje total acumulado (`score`)
- ✅ Vidas restantes (`lives`)
- ✅ Niveles completados (`completedLevels`)
- ✅ Medallas/insignias desbloqueadas (`unlockedBadges`)

### ¿Dónde se guarda?

Se utiliza la **API `localStorage`** del navegador, bajo la clave: biocore_progress_v2

### ⚠️ Consideraciones importantes

1. **Es por navegador y dispositivo.** Si abrís el juego en otra computadora, otro celular u otro navegador (Chrome, Firefox, Edge), el progreso **no se comparte automáticamente**. Cada uno tiene su propio guardado local.
2. **Si borrás los datos del navegador** (caché, cookies, almacenamiento local), el progreso se pierde.
3. **Modo incógnito / privado:** En ventanas de incógnito, el progreso se borra al cerrar la ventana.
4. **No hay sincronización en la nube.** Si querés guardar tu progreso entre dispositivos, podrías exportar/importar manualmente desde las DevTools (ver más abajo).

### ¿Cómo reiniciar el progreso?

Dentro del juego, en el panel principal, hay un botón **"Reiniciar progreso"** que borra todo (puntaje, vidas y medallas). También podés hacerlo manualmente desde la consola del navegador (F12):

```jsx
localStorage.removeItem('biocore_progress_v2');
location.reload();
```

### **¿Cómo hacer una copia de seguridad manual?**

Abrí la consola del navegador (F12), pegá esto y guardá la salida en un archivo de texto:

javascript

```
copy(localStorage.getItem('biocore_progress_v2'));
```

Para restaurarlo en otro navegador:

javascript

```
localStorage.setItem('biocore_progress_v2', 'PEGAR_AQUÍ_EL_CONTENIDO_COPIADO');
location.reload();
```
